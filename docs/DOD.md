# Definition of Done

A backlog item is only "Done" when every point below is true.

1. All unit tests pass.
2. Code is refactored (Boy Scout Rule applied): the code is left cleaner than it was found.
3. Rationale document updated: any design decision is recorded in `docs/RATIONALE.md`.
4. Every acceptance criterion of the user story is met and checked.
5. The change is committed and pushed to `main` with a clear, prefixed commit message.
